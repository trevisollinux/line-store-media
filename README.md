# line-store-media

Mídia servida para a publicação no Instagram, usada por
[line-insta-poster](https://github.com/trevisollinux/line-insta-poster).

Este repositório é **público por necessidade**: quem baixa os arquivos é o
servidor da Meta, que não tem credencial nenhuma. Repositório privado
simplesmente não funcionaria para isso.

- `inbox/` — fotos e vídeos vindos da pasta do Drive
- As URLs de publicação usam o jsDelivr, que espelha este repositório e
  serve com o tipo de conteúdo correto (o `raw.githubusercontent.com` não).

Não edite nada aqui à mão: os arquivos são escritos pelos workflows.
